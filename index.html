🔑 API Key Information

To use external services (Maps, Weather, etc.), you need an API Key. Store it in a variable in your JS tab. Never share your keys publicly!

📱 How to Convert to APK (Android Studio)

  1. Export your project as a ZIP from this editor.
  2. Open Android Studio and create a new "Empty Activity" project.
  3. Add a WebView to your activity_main.xml.
  4. Create an assets folder in src/main/ and paste your project files there.
  5. In MainActivity.java, load the file:
    webView.loadUrl("file:///android_asset/index.html");
  6. Go to Build > Build APK(s) to generate your mobile app!

💡 Pro Tips

  • Use Inspect Element to find exactly where your code is in the editor.
  • Hover over colors in the editor to see a quick preview bubble.
  • Resize the Console window by dragging the handle above it.
  • Use the Mobile App button to start with a professional, responsive template.

❓ FAQ (Frequently Asked Questions)

Q: How do I run my code?
A: Code runs automatically as you type, or you can click the Run button manually.

Q: How do I add images?
A: Use the Import button to upload images, or use online URLs in your <img> tags.

Q: Can I save my project?
A: Yes! Use Save ZIP to download all your files for later use.

🔑 API की (Key) जानकारी

बाहरी सेवाओं (Maps, Weather आदि) का उपयोग करने के लिए, आपको एक API की आवश्यकता होती है। इसे अपने JS टैब में एक वेरिएबल में रखें। अपनी की (Keys) को कभी भी सार्वजनिक रूप से साझा न करें!

📱 APK में कैसे बदलें (Android Studio)

  1. इस एडिटर से अपने प्रोजेक्ट को ZIP के रूप में डाउनलोड करें।
  2. Android Studio खोलें और एक नया "Empty Activity" प्रोजेक्ट बनाएं।
  3. अपने activity_main.xml में WebView जोड़ें।
  4. src/main/ में एक assets फ़ोल्डर बनाएं और अपनी प्रोजेक्ट फाइलें वहां पेस्ट करें।
  5. MainActivity.java में, फाइल लोड करें:
    webView.loadUrl("file:///android_asset/index.html");
  6. अपनी मोबाइल ऐप बनाने के लिए Build > Build APK(s) पर जाएं!

💡 प्रो टिप्स (Tips)

  • एडिटर में आपका कोड बिल्कुल कहां है, यह जानने के लिए Inspect Element का उपयोग करें।
  • कलर कोड पर माउस ले जाकर उसका तुरंत प्रीव्यू देखें।
  • कंसोल विंडो के ऊपर के हैंडल को खींचकर उसका आकार बदलें।
  • प्रोफेशनल और रिस्पॉन्सिव टेम्पलेट के लिए Mobile App बटन का उपयोग करें।

❓ अक्सर पूछे जाने वाले प्रश्न (FAQ)

प्रश्न: मैं अपना कोड कैसे रन करूं?
उत्तर: टाइप करते समय कोड अपने आप रन होता है, या आप Run बटन पर क्लिक कर सकते हैं।

प्रश्न: मैं इमेज कैसे जोड़ूं?
उत्तर: इमेज अपलोड करने के लिए Import बटन का उपयोग करें, या <img> टैग में ऑनलाइन URL का उपयोग करें।

प्रश्न: क्या मैं अपना प्रोजेक्ट सेव कर सकता हूं?
उत्तर: हाँ! बाद में उपयोग के लिए अपनी सभी फाइलों को डाउनलोड करने के लिए Save ZIP का उपयोग करें।
